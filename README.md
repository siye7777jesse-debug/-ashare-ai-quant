# A股双引擎量化研究平台（研究原型）
手机浏览器打开 GitHub Pages。无需本地 CSV，免费公开日线数据按以下顺序获取：先读取本站 `data/<股票代码>.json` 缓存，若缺失则尝试东方财富公开接口。接口可能限流、跨域失败，失败不会生成虚假行情。

## 当前功能
- `index.html`：输入股票、日期、回测资金，查看普通回测与样本外对照。
- `backtest.js`：固定策略（5/20均线、20日突破、超跌反转）的教育用途单股回测。收盘生成信号，次日开盘模拟撮合；100股整数手、T+1、佣金下限、固定滑点、卖出印花税分段、主板近似一字板阻断。
- `validation.js`：按时间**固定70%样本内、30%样本外**对照。后30%交易从分割日期开始，之前的历史仅参与指标计算，不形成仓位。两段各自以配置的初始现金从空仓开始。
- `update_data.py`：采集公开日线；`.github/workflows/update-data.yml` 定时尝试采集并提交 JSON 文件；采集失败时保留旧数据。
- `.github/workflows/test-backtest.yml`：在 PR 中执行 Node.js 离线回归测试，覆盖账本、T+1、样本时间边界、未来数据扰动隔离。

## 如何使用样本外对照
1. 打开手机网页，输入代码与日期，点击“自动获取公开历史数据”（至少100条有效日线）。
2. 先**固定**股票、策略、手续费和初始资金，运行普通回测。
3. 点击“运行样本内 / 样本外对比”，查看各段独立计算的累计收益、年化收益、最大回撤、夏普比率和买卖次数。
4. **注意**：你如果已经看过全区间结果、用后30%的表现挑选参数或反复调优，后30%便不再是独立样本外数据。当前功能属于固定规则的时间切分检查，不提供统计显著性保证或真正封存测试集的权限控制。


## V7 多股票统一日期样本外验证
- 手机网页新增“多股票样本外对比”：可勾选百大集团、上海九百、中百集团、中际旭创、工业富联和贵州茅台，统一指定样本外起始日期（默认 2025-01-01）。
- 所有股票采用相同的选定策略、初始资金、佣金与日期区间；各股**独立资金与仓位**，不是同一账户同时持仓，也不提供组合收益。
- 每只股票在共同日期之前至少需要 60 条、之后至少 30 条日线；数据不足或接口失败会逐股列出，**不冒充零收益**。
- GitHub 缓存目前可能还没有生成。网页先请求 `data/<code>.json`，失败时尝试东方财富公开接口；后者可能受 CORS、限流或临时故障影响。数据更新工作流也配置为首次部署时尝试采集，但不能保证外部接口成功。
- 横截面显示样本外盈利股票数、跑赢各自买入持有股票数、样本外收益率中位数。**这些不是投资组合回报**。
- 测试 `node test_multistock.cjs` / `node test_web_ui.cjs` 覆盖同一日期分界、未来行情隔离、失败数据、网页结构及脚本语法。
- 当前仅有六只预设研究股票，属于人为选择的小样本；不能代表全A股市场，尚未覆盖历史股票池、退市股票和生存者偏差。

## 验证与局限
`node test_backtest.cjs && node test_accounting.cjs && node test_validation.cjs` 为不依赖网络的单元测试。
不复权数据可能受到分红与除权影响；未支持退市股票、历史 ST 状态、完整交易所涨跌幅规则、停牌、按成交量逐笔撮合、资金管理、多股票组合、持仓跨区间连续性及真正的AI自主策略优化。样本外/样本内默认各自空仓重新开始，不能将两段收益直接相加当作一次连续实盘回测。平台仅供量化研究与程序验证，不构成投资建议。
