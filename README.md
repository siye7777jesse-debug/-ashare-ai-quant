# A股双引擎量化研究系统

[手机网页](https://siye7777jesse-debug.github.io/-ashare-ai-quant/)继续使用原有 GitHub Pages。网页支持按中文名称或代码搜索、单股回测、固定 70/30 时间切分和 2–10 股统一日期对比。免费公开数据，无需 CSV 或付费 AI API。

## 计算与数据

- 在电脑或 GitHub Actions 运行 `python update_stocks.py`、`python update_data.py`、`node research_report.cjs`。手机“逐年样本外研究”直接读取预计算结果。自定义参数与临时选股目前在浏览器计算。
- 日线使用东方财富 `fqt=0` 的原始 OHLC 和成交量（手）。北京时间 16:00 前只请求前一日及以前的行情。定时刷新用上证指数确定最近已观测到的交易日；六只缓存股票缺少该日日线时报告失败，由维护者核实停牌或数据缺失。日期、重复、非有限值、异常高低价、旧交易日丢失及证券身份均有检查。
- 目录首选东方财富分页列表，唯一代码数必须等于接口报告总数。本次接口共返回 5,931 个唯一代码。剔除 3 个定向可转债代码和 1 个存托凭证代码后，保留 5,927 个名称检索条目，其中含历史退市代码。备用源为巨潮资讯 A 股披露目录，包含部分旧代码、曾上市公司。页面显示实际来源和采集时间。目录供搜索，不能重建历史股票池。六只默认股票有本地行情缓存，其他代码需要公开接口可访问。
- 分配记录来自东方财富 `RPT_SHAREBONUS_DET` 的已实施方案，按每股换算。送转事件另查新浪分配明细的上市日，核对除权日与比例。数据文件保留来源，预计算报告记录行情和分配文件的 SHA-256。同一份数据和参数可重复生成同一份报告。
- 单股与多股网页共用 `market_data.js`。指定区间缺少已核实的分配历史、证券不匹配或响应不完整时显示错误。在线接口受限时不能保证所有股票可用。

## 回测和验证口径

收盘生成信号，次一根日线开盘成交。信号价格按已实施的现金分红、送转逐日衔接，采用理论除权参考价（前收盘价减每股税前现金，再除以一加每股送转数）。成交和持仓市值使用原始价格。差异化分红、回购专户等可能使理论参考价与交易所公布值不同。

现金分配在除息日按原有持股确权，作为独立税前权益保留至期末，全程不用于再次买入。新增股份以原始价格计值，经核实的上市日之前禁止卖出；缺少上市日或遇到分配数不能确定的零碎股时，相关持仓回测报告失败。期末权益等于可用现金、股票市值和累计分红权益之和。尚未模拟股息税、配股认购、缩股、退市清算、实际派息到账或过户费。

普通主板、创业板、科创板、北交所采用各自的普通限价近似。创业板比例按 2020-08-24 分段。开盘触及不利方向限价时保守跳过，即使随后打开涨跌停也不回填成交。零成交量不成交。主板和创业板买入按百股整数手，科创板和北交所分别设置最低 200、100 股，超出部分以 1 股递增。该模型尚缺历史 ST、上市初期无涨跌幅限制、竞价排队、单笔申报上限和容量约束。佣金默认最低 5 元，卖出印花税按 2023-08-28 分段；滑点作为开盘成交的额外成本计入。账本不做逐笔分币舍入。

同期基准在评价期从空仓开始，以相同可用资金在首个可买开盘建仓，沿用策略的成交限制、滑点、费用、分配和期末市值口径。未平仓头寸均按末日收盘估值。年度窗口先使用历史预热，再从空仓按固定 5/20 均线、10 万元初始资金独立运行。窗口互不重叠，当年未结束的区间标注为年内截至。各年收益不能直接拼成连续实盘收益。

固定分割的既有代码未发现读取未来收盘价决定此前交易的问题。观察股票由人挑选、当前目录有生存者偏差、反复查看样本外结果可导致选参过拟合。各股独立账户，失败逐股保留。研究工具尚未建立历史时点股票池、封存测试集、完整投资组合或策略搜索的多重检验。引擎 A 自主提出和检验假设、引擎 B 的主线/板块轮动/分歧买入规则仍待实现。

## 验证与发布

```sh
python -m unittest discover -v
node --test test*.cjs
node research_report.cjs --check
```

手动或工作日定时刷新会在独立 runner 中重新采集、预计算并测试快照。全部成功后仅向数据分支提交，并发起数据 PR。仓库需允许 Actions 创建 Pull Request；禁用时提交 PR 的步骤会报错。代码与数据进入主分支后由现有 Pages 配置发布。PR 的离线测试不依赖上游行情接口。
